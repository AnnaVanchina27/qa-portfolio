# QA Portfolio

Ручное тестирование (web, mobile), API‑тестирование, автотесты на Python (pytest).

## Проекты

### Яндекс Самокат

В папке `samokat/` — артефакты по проекту «Яндекс Самокат»:

- чек‑листы,
- тест‑кейсы,
- баг‑репорты (web + mobile),
- коллекция Postman (API‑тесты),
- автотесты API на pytest и скрипты для проверок в БД (ссылка на репозиторий с автотестами).

[Подробнее о проекте](samokat/README.md)

### LINKA (Яндекс Мастерская)

В папке `linka/` — артефакты командного проекта на реальном продукте:

- тест-дизайн: классы эквивалентности, граничные значения, таблицы принятия решений,
- коллекции Postman (API-тесты, прогоны через Runner),
- баг-репорты в GitHub Issues с локализацией через DevTools.

[Подробнее о проекте](linka/README.md)
