# Яндекс Самокат - тестирование сервиса аренды самокатов

## Описание проекта

Проект посвящён тестированию сервиса аренды самокатов "Яндекс Самокат".  
Выполнялось:

- UI/UX‑тестирование веб‑формы заказа самоката.
- Регрессионное тестирование мобильного приложения.
- Ретест исправленных багов по мобильному приложению.

## Что тестировалось

### Web (форма заказа самоката)

- UI‑элементы формы заказа.
- Корректность отображения полей, кнопок, подсказок.
- Валидация введённых данных.
- Основные пользовательские сценарии: выбор самоката, оформление заказа.

### Mobile (приложение «Самокат»)

- Основные сценарии использования приложения.
- Регрессионное тестирование после исправлений.
- Ретест ранее найденных багов.

### API‑тестирование

В файле `Samokat.postman_collection.json` находится коллекция Postman с запросами к API сервиса «Яндекс Самокат».

Что проверялось:

- Основные эндпоинты: создание заказа, создание курьера, получение заказа по номеру и т. д.
- Корректность ответов (статус‑коды, структура JSON).
- Обработка ошибок.

### Автотесты

Автотесты API для этого проекта (pytest + requests) находятся в отдельном репозитории:  
[yandex_samokat_api_project](https://github.com/AnnaVanchina27/yandex_samokat_api_project)

Там же есть скрипты для проверки данных в БД и примеры запросов.

## Артефакты тестирования

В этой папке находятся файлы:

- "Самокат web- Чек-лист.pdf" - чек‑лист проверок веб‑формы заказа.
- "Самокат web- Таблица КЭ ГЗ.pdf" - тест‑кейсы и граничные значения (КЭ — ключевые сценарии, ГЗ — граничные значения).
- "Самокат web- Баг-репорты.pdf" - баг‑репорты по веб‑форме.
- "регрессионное тестирование Самокат mobile - Баг-репорты.pdf" - баг‑репорты по мобильному приложению.
- "Samokat.postman_collection.json" - коллекция запросов Postman.

## Как пользоваться

1. Откройте чек‑лист - список проверок по основным функциям.
2. В таблице КЭ/ГЗ - подробные шаги для ключевых сценариев.
3. В баг‑репортах - оформленные баги с шагами воспроизведения, ожидаемым и фактическим результатом.
4. В коллекции API - примеры тел запросов к API (Postman).
5. Автотесты API на pytest и скрипты к БД - в отдельном репозитории:  
   [yandex_samokat_api_project](https://github.com/AnnaVanchina27/yandex_samokat_api_project)

## Инструменты

- Ручное тестирование (web, mobile).
- UI/UX‑тестирование формы заказа.
- Регрессионное и ретест‑тестирование мобильного приложения.
- API‑тестирование с помощью Postman (коллекция запросов к API сервиса).
- Автотесты API: Python, pytest, requests (в отдельном репозитории).
- Документирование в Google Docs / Google Sheets, экспорт в PDF.
